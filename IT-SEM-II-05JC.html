Add New User useradd
Create a new user account on the system. Equivalent to useradd [options] username
$ useradd -m -s /bin/bash -G sudo,docker -c "Full Name" username

Change Password passwd
Set or change a user's password. Also lock/unlock accounts. Equivalent to passwd [options] username
$ passwd username  |  passwd -l username (lock)  |  passwd -u username (unlock)

Modify User usermod
Modify an existing user account — change name, shell, groups, home dir, lock/unlock. Equivalent to usermod [options] username
$ usermod -aG docker username  |  usermod -s /bin/zsh username  |  usermod -l newname oldname

Delete User userdel
Remove a user account from the system. Optionally remove home directory and mail spool. Equivalent to userdel [options] username
⚠ WARNING: userdel -r permanently removes the user's home directory and mail spool. This cannot be undone.
